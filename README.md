# Roam Transit 8X availability monitor

GitHub Actionsで、2026年9月10日・11日の **8X Reservable Super Pass（大人1名）** を毎時確認します。

- 既存予約の変更・キャンセル・購入は行いません。
- 条件に合う新しい空席または残席増加だけをIssue #1へ通知します。
- 変化なし、対象外、サイト取得失敗時は通知しません。
- 通知済み状態は `state.json` に保存し、同じ状態を再通知しません。
- 現在から9月11日まで、毎時17分（America/Los_Angeles）に実行します。監視期間終了後は空席確認をせず終了します。

## 通知条件

- 9月11日：往路10:15より前、または復路21:00より前の新規空席。
- 9月10日：往路10:15以前かつ復路21:00以前の同日往復で、少なくとも一方が現在の予約より早い新規組み合わせ。

## 手動確認

Actionsの `Roam Transit availability monitor` から `Run workflow` を実行できます。結果に関係なく予約は変更されません。

監視対象期間終了後は自動的に確認処理をスキップします。
